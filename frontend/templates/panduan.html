Panduan Website

Ikuti langkah berikut untuk menggunakan JEJAK TUMBUH dari awal sampai melihat hasil pemeriksaan.

  1. Langkah 1

    Buka landing page

    Landing page memiliki tiga tahap. Gunakan tombol Next dan Previous untuk membaca sambutan, petunjuk singkat, lalu membuka login atau registrasi.

  2. Langkah 2

    Login

    Pada tahap Masuk/Daftar, pilih Masuk, lalu isi email atau username dan kata sandi. Kader memakai ID akun yang diberikan pengelola; orang tua dan ibu hamil memakai akun masing-masing.

  3. Langkah 3

    Registrasi pengguna baru

    Pilih Daftar Baru, lalu pilih Ibu Hamil atau Orang Tua Balita. Kader tidak mendaftar mandiri; akun kader disiapkan pengelola. Masukkan nama, email, kata sandi, dan konfirmasinya.

  4. Langkah 4

    Isi biodata sesuai akun

    Formulir menampilkan kolom sesuai pilihan. Ibu Hamil mengisi pendamping, usia, dan usia kandungan. Orang Tua Balita mengisi data orang tua dan balita, termasuk tanggal lahir. Lengkapi alamat, RT, RW, dan dusun.

    Gunakan dashboard

    Buka dashboard {% endif %}
  6. Langkah 6

    Buka fitur yang dibutuhkan

    {% if session.get('user_role') == 'Kader' %}

    Buka data peserta {% elif session.get('user_role') == 'Orang Tua Balita' %}

    Buka edukasi untuk membaca materi gizi dan MP-ASI. Kalender menampilkan jadwal kunjungan yang tercatat.

    Buka edukasi {% else %}

    Buka Buku KIA dan edukasi untuk mempelajari informasi kehamilan. Kalender menampilkan jadwal kunjungan yang tercatat.

    Buka Buku KIA {% endif %}
  7. Langkah 7

    Catat pemeriksaan

    {% if session.get('user_role') == 'Kader' %}

    Pilih menu pemeriksaan balita atau ibu hamil, pilih peserta, isi hasil ukur dan catatan, lalu simpan. Masukkan jadwal berikutnya agar muncul di kalender.

    Pemeriksaan balita Pemeriksaan ibu hamil
    {% else %}

    {% endif %}

    Lihat dan buat laporan

    {% if session.get('user_role') == 'Kader' %}

    Buka laporan {% else %}

    {% endif %}

    Periksa riwayat dan jadwal
